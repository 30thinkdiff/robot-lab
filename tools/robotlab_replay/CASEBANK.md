# 成败组合诊断样本库

这是一组按已知结果选择的**机制复盘案例**，不是用来估计全体LIBERO成功率的随机测试集。表格中的自选方法必须来自同一实验协议组、task、init与评测seed；不强制包含H50/H20。视频统一环境步不等于统一操作阶段。另有任意条件的探索性对照入口，明确区分于本库的同条件分组。

**当前决策（2026-11-12）：旧660计划已在119完整回合边界安全暂停，新增评测0回合。** 8个物理状态、7组跑齐15配置，四类基础模式和主要机制翻转都有完整回放。其余541条保留为原计划但不默认续跑。覆盖矩阵、43条优先复盘索引与独立缩减决策见[研究审计](../../studies/policy_generalization/results/20261112/casebank_research_v2/RESULTS.md)。下文660设计/首批27条描述为原计划历史，不表示队列仍运行。

## 现在如何使用

重启本地Replay，再点顶部 **成败组合样本库**：

```bash
python3 -X utf8 tools/robotlab_replay/server.py --open
```

1. 默认来源为 `replay_casebank_20261112_001`，启用完整资料筛选；原快捷组合下参照选择 `MLP / OGG`。
2. 勾选“仅视频、trace和动作齐全”，选择三方法的成败组合。
3. 点击 `H50 ↔ 参照` 或 `H20 ↔ 参照`。视频、曲线、事件及动作共用环境步；右侧可切换主选/对照诊断。
4. 可切换五模型OGG、LVM/OGG、混合引导、规划/已执行预设，或展开自选多个方法。逐列过滤结局，再从“主选/对照”选择任意两者；无需把H50或H20作为一方。数字按真实记录重新计算，没有的组合为0、缺失结果为未记录。
5. 研究偶然性时选择 `confirmation`：新评测seed为2000、2001、2002。`discovery_replay`复现旧的筛选案例，两者分开观察。

默认完整筛选还要求视频绑定到本回合自己的录制证据。只有相同内容SHA而缺原trial绑定的旧视频可独立播放，不算完整同步资料。样本库新增独立Hybrid、规划/已执行闭环及Horizon Pilot协议组；不会跨来源拼接。主选资料区的本地视频筛选同步生效，强制接口检查仍与自然成败库分开。

## 为什么需要补测

旧正式五模型在相同60组条件中，按H50/H20/MLP-OGG顺序共有：001=3、000=4、011=8、111=42、010=1、101=2、100=0、110=0。旧策略通常只保留失败视频，成功案例缺视频，旧回合也缺完整动作/梯度，不能事后恢复。

本轮冻结11个物理task/init，每个保留一个旧筛选seed，再加3个新seed，共44组条件。每组15种配置，共660个完整回合：

- H50、H20，保持50步生成动作块；H20执行前20步后清空队列。
- MLP、T-H1、T-H3、A10-H1、A10-H3，各自原LVM与OGG，共10种。
- T-H1检测/生成目标 → A10-H1引导的混合OGG。
- 同一A10-H1与同一新固定规则下的 `planned_lvm`、`executed_lvm`，均无OGG。

这里“原始Corrector”特指**MLP架构、训练seed42、原鲁棒LVM及首动作OGG**，冻结权重SHA以05d55ba94521开头；不是最初queue的另一份ac822权重。训练seed固定，新的评测seed重复只检验执行噪声稳定性，不代表多训练seed置信区间。

精确样本选择与旧trial SHA见[冻结选择清单](../../studies/policy_generalization/corrector/manifests/replay_casebank_20261112.json)。每种组合最多选两个不同物理状态；优先补齐四种核心三方法对照，其后完成其他方法与新seed。

## 每条新回合保留什么

- 成功与失败均保留视频；独立trial SHA绑定、固定录制源码证据、逐帧PTS和 `frame_map.jsonl`。
- 每步实际提交到底层控制器的原始动作、规范化动作、提交是否返回；另有真实队列/动作块编号、VLA生成块数组和调用计数。
- Corrector逐步分数、阈值、跳过/取消、预测origin/到期、监测有效区间及重规划事件。
- OGG实际Loss、完整梯度、候选动作更新前后及作用slot；触发时保存检测输入、预测变化、观测变化和纠偏目标等数值NPZ。
- 回合耗时、推理/监测/采集开销、峰值显存、全部协议和权重/源码SHA。

只记录真实数组，不重新运行额外模型来伪造旧预测；预测输入仅在内存保留有限时域，触发时落盘。不是全回合所有视觉Tensor，也不是机器人测量状态。Replay目前展示动作、OGG更新范数和目标摘要；完整NPZ已导入，但尚无任意Tensor浏览器。记录开销会影响墙钟，不能将本轮延迟直接当成无记录版本的部署延迟。五冻结预测器常驻显存，峰值包含公共工作集，不能据此给单模型最小显存需求排名。

控制20Hz，动作条件按10Hz取0、2、…、18；预测跨度1秒/20控制步。录像帧n对应提交u_n之前的Z_n，末动作后的Z_N未保留。远端用已有PyAV读取实际PTS，本地再用ffprobe和独立录制绑定核验，不凭FPS强行同步。

## 查看、暂停、恢复与取回

下面用自己的SSH别名；共享连接可加 `--control-path /path/to/private.sock`，不把密码写入脚本或仓库。

```bash
python3 scripts/corrector_casebank_remote.py status --ssh-host <SSH别名>
python3 scripts/corrector_casebank_remote.py pause --ssh-host <SSH别名>
python3 scripts/corrector_casebank_remote.py fetch --snapshot --ssh-host <SSH别名>
python3 scripts/corrector_casebank_remote.py fetch --wait-and-fetch --wait-minutes 540 --ssh-host <SSH别名>
```

`pause`只创建STOP，在当前回合结束后停止；不杀进程。恢复前先检查状态；若是手动STOP，核对后在远端显式移除本轮STOP，再运行 `resume`。它复用已部署代码、核验协议/权重、跳过完成回合；不会用新本地代码覆盖原部署。目录冲突、其他GPU任务、确定性程序错误均停止报告，不无限重启。

远端本轮根目录 `/root/robotlab_replay_casebank_20261112_003`，日志 `launch.log`；新结果位于系统盘，减少数据盘压力。默认8小时预算，新文件上限4GiB，系统盘/数据盘/有效内存保底分别5/3/6GiB；检查实际cgroup，不以宿主机总内存冒充配额。触及边界即暂停，不自动删除旧数据。

最初安排的本地自动取回进程在共享连接断开时退出；本轮重连后已手动请求安全暂停并取回119回合，**目前没有自动恢复或取回队列在运行**。旧日志位于忽略目录 `.local/casebank_downloads/auto_fetch.log`，不能把最后一条旧进度当作当前状态。以后关闭本地电脑不会终止远程后台实验，但会中断取回。导入后需重启本地Replay，它只索引同study最新且最完整的批次，避免快照重复计数。

`fetch --snapshot`只打包已完成的不可变trial及对应attempt，不复制正在写的回合。ZIP/视频/数值数组通过校验后追加到 `.local/import_batches/`，不覆盖历史。完整Tensor、视频、SSH地址和连接socket均不提交Git。

本地空间不足以解压整个包时，导入器保留已验证ZIP，只解出119段视频及录制证据；动作、trace和数值数组按需从ZIP读取。保留至少512MiB空闲空间；连视频也容纳不下时停止，不删除旧资料。不会把缺少本地全量解压误报成未记录。

## 技术检查与限制

- GPU开始前确认15组训练完成，旧队列已因预算正常暂停，无旧GPU进程。
- 五模型shape、有限非零梯度、原OGG更新公式及权重只读检查通过。采用同一次真实梯度核对原更新恒等式；H3的不同AMP-BF16调用存在微小数值波动，未改精度、目标或临时缩放。
- 一条完整T-H1 OGG任务做了无记录/有记录的控制对照：168步、相同结局，实际提交动作逐元素完全一致，最大差0。这是记录接口验证，不当成额外正式样本，也不保证所有CUDA重复都位级确定。
- 早期V1在跨调用数值检查停止，V2因远程没有ffprobe停止；二者正式回合均为0，现场保留。V3改为同调用梯度验证和已有PyAV，无第三方包或环境变更。
- 八种结局组合不保证都会存在；“全模型所有可能结局排列”也不能靠有限回合穷举。新增真实结果直接进入同一筛选界面，不捏造缺失模式。
