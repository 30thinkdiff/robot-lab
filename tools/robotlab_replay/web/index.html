配置释义 选择回合后显示

两个H含义不同：VLA的H50/H20/H10是每块执行50/20/10个控制步；Corrector的H1/H3是1/3帧视觉输入。A10表示10个动作条件，所有Corrector输出都是视觉特征变化。

模型视觉输入动作条件 / OGG可影响位置
MLP、T-H1当前帧单动作 / 首动作
T-H3最近3帧单动作 / 首动作
A10-H1、A10-H3当前帧 / 最近3帧10动作 / 偏移0,2,…,18的10个位置

本轮：数据10Hz、预测跨10个数据步＝1秒；控制20Hz、在线跨20步。H3视觉位置是t−4、t−2、t；A10按0、2、…、18控制步采样，不是连续10个20Hz动作。原始采集物理时钟未独立验证。

monitor只评分；lvm检测后普通重规划；ogg检测后重规划并引导动作生成。混合A/B/C分别是T-H1→T-H1、T-H1→A10-H1、A10-H1→A10-H1。单/多动作是预测器的输入与梯度作用范围，不是预测器输出动作。

planned_lvm / executed_lvm使用A10-H1，分别以未来计划或真实已提交历史动作评分，均无OGG。single_lvm / single_ogg是单动作T-H1，采用原监测规则，并非MLP；与新规则不能视为纯架构消融。
