# J36M-454 全量数据训练与闭环评测

2026年11月21日完成训练和184个正式闭环回合。J454在共同验证集上的三层原始MSE均低于J70，普通Object10成功数持平，Plus历史诊断子集净增1例。在这92组闭环条件中，开启OGG未改变任何一个终局；580次正式引导均产生非零动作梯度。

## 数据与训练

保留J70的36,793,536参数架构和三层损失权重（Block 2、Block 8、Connector分别为0.25、0.25、0.50）。J454使用完整454条示范、66,984帧，以历史样本锚点 `t>=2` 构建49,447个训练样本和12,089个验证样本，分别来自364和90条Episode。两层FP16特征原地复用，Connector的INT8数据和FP16尺度与历史量化缓存逐项校验。训练集RMS重新计算，验证集不参与拟合。

固定训练seed42、FP32、每批8条、梯度累积4次，训练60轮共92,760次更新。按验证集Connector归一化MSE选出第39轮，已重载核验。第39轮的Block 2、Block 8和Connector归一化MSE依次为0.549892、0.464523和0.344901。Block 2自身最低点出现在第33轮，其余两层在第39轮。第60轮的三层指标均未刷新最低值。

完整首轮训练加验证用时670.08秒，累计60轮用时34,047.53秒（9小时27分钟），PyTorch峰值分配1.754 GiB。128样本预检中，无损紧凑搬运加4个worker为72.21样本/秒，原路径为23.09样本/秒，输入、目标、损失和更新通过一致性检查。小批量对照受启动顺序和缓存影响，正式整轮仅实测了选定管线。第39轮共享融合层梯度范数及方向余弦也已保留。[训练曲线](training_curve.csv) · [权重SHA与验收收据](summary.json) · [训练与评测配置](../../../corrector/j36m454_20261120/OPERATIONS.md)

## 闭环与配对结果

Object10使用10任务×3个初始状态×2个评测种子，每方法60回合。Plus复用此前确定的32个扰动条件，每方法32回合，评测种子1000。两组J454都沿用动态LVM、20步到期、4步预热、中断时保留待到期视觉预测；J454-OGG在事件重规划时沿用原余弦引导（`eta=1`、`guidance_every=3`）。三层评分权重和可靠性下限在20条独立默认视角H50轨迹上按历史规则重标定。32次Plus场景reset/一步检查和4次强制诊断均另计。

| 方法 | Object10 | Plus历史诊断 |
|---|---:|---:|
| H50（历史） | 44/60 | 7/32 |
| H20（历史） | 51/60 | 20/32 |
| MLP-LVM（历史） | 55/60 | 11/32 |
| MLP-OGG（历史） | 55/60 | 11/32 |
| S2-LVM / S2-OGG（历史） | 53/60、53/60 | — |
| S8-LVM / S8-OGG（历史） | 53/60、54/60 | — |
| J70-LVM / J70-OGG（历史） | 55/60、55/60 | 9/32、9/32 |
| **J454-LVM / J454-OGG** | **55/60、55/60** | **10/32、10/32** |

- **Object10**：与同模式J70相比，两种J454各获4例、失4例；与同模式MLP相比各获3例、失3例。相对H20均获7例、失3例。
- **Plus**：与同模式J70相比，两种J454各获3例、失2例。H20成功的20例包含J454成功的全部10例，因此J454相对H20获0例、失10例。
- **OGG**：与本次J454-LVM相比，60组Object10和32组Plus的终局均逐例相同。重规划、生成次数和动作轨迹允许不同。

新旧结果按条件和评测种子配对。J454内部同条件核对了初始状态、首输入和首噪声签名；跨批历史对照保留机器与采集配置差异。J70与J454的训练锚点和在线标定数值也有差异。结果支持共同验证集上的预测误差下降，现有闭环样本对成功收益的证据有限。Plus历史扰动子集适合诊断，覆盖范围限于既有两项基础任务和32个条件。 [逐回合](trials.csv) · [配对汇总](paired_comparisons.csv) · [翻转索引](outcome_flips.csv)

## 完成与归档

两套正式队列的最终记录分别为120/120、64/64，错误均为0。Object10中途因实例内存保护暂停，清理训练文件页缓存后保留前96条并续跑。Plus首启缺少MagickWand，补齐独立运行库并完成32项环境预检后继续，原评测计划与权重保持一致。

2号机的实验目录 `j36m454_20261120_001/replay_exports/` 已归档两套共184条回放。压缩包名、字节数和SHA，以及逐回合源记录与监测Trace的SHA见 [机器摘要](summary.json) 和 [逐回合索引](trials.csv)。本地只同步轻量统计。完整视频、动作轨迹、张量和权重留在远端，按指定条件或trial ID取回。
